# РГР — вариант №5. Применение ИИ в образовании

## Запуск в Windows (VS Code)

1. Скачать или клонировать репозиторий и открыть его корневую папку через File → Open Folder.
2. Установить Python 3.12 и расширения VS Code Python и Jupyter.
3. В терминале выполнить команды для своей оболочки.

Git Bash:
```bash
py -3.12 -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
```

PowerShell:
```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

4. Открыть `RGR_Variant5.ipynb`, выбрать ядро `.venv` и нажать Run All.
5. Для первого запуска нужен интернет для загрузки ресурсов NLTK. После этого вычисления по сохранённым данным выполняются офлайн.

Таблицы и графики отображаются внутри ноутбука. `LIVE_HTTP = False` сохраняет исходный корпус исследования; при `True` выполняется повторный запрос OpenAlex, ответ сохраняется отдельно и не заменяет размеченные данные. При необходимости API использует ключ из переменной `OPENALEX_API_KEY`.

Исходные данные находятся в папке `data/` (JSON, CSV, исходный HTTP-ответ и журнал запроса). Ноутбук является итоговым отчётом по РГР: содержит теорию, код, таблицы, графики и выводы.
